# Using Generative AI Tools - Boon or Bane

This repository contains all the files used for the study "Using Generative AI Tools - Boon or Bane".



What does git clone do？ 

Git clone creates a functional copy of a remote repository on your local computer. It downloads the entire project so you can work on files offline and manage changes through your local terminal or desktop application.  



What does github fork do？

GitHub fork creates a copy of someone else's repository specifically on your own GitHub account. This allows you to experiment with changes or contribute to projects without affecting the original source code until you submit a pull request.  



Differences between git clone and github fork.

The main difference is the location of the copy. Forking happens entirely on the GitHub server between two accounts. Cloning happens between the GitHub server and your personal hardware, enabling you to physically edit files on your machine.
