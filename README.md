what does git clone do; what does github fork do. Differences between git clone and github fork



git clone downloads a copy of a repository from GitHub to your local computer. It allows you to work on the project files locally and save changes using Git.



A GitHub fork creates a copy of another person’s repository under your own GitHub account. It allows you to make changes independently without changing the original repository.



The main difference is that git clone copies a repository to your computer, while a fork copies a repository to your GitHub account. Forking is usually used for collaboration, while cloning is used for local editing and development.
