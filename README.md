What does `git clone` do; what does GitHub's fork do? What are the differences between `git clone` and GitHub's fork?

A `git clone` downloads/clones a git repo down to your local drive, allowing for local development. While GitHub's fork will create a new copy of the repository under your account on GitHub's servers. A fork will also allow pull requests to be created through GitHub allowing for contributions back to the parent project.
