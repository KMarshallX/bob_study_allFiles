# Using Generative AI Tools - Boon or Bane

This repository contains all the files used for the study "Using Generative AI Tools - Boon or Bane".

The project is organized by document type so it is easier to find source material, analysis files, and report drafts without having to search through every file.

## Project Structure

The repository is divided into five main folders:

- [additional_materials/](additional_materials/) stores information sheets, photos, and other supporting media.
- [drafts_and_reports/](drafts_and_reports/) stores draft research proposals, conference papers, and final reports.
- [literature_review/](literature_review/) stores books, review material, and related article-style reference sources.
- [qualitative_analysis/](qualitative_analysis/) stores interview transcripts, consent forms, qualitative summaries, and visualisations.
- [quantitative_analysis/](quantitative_analysis/) stores survey data, survey questions, analysis scripts, CSV/Excel files, and survey analysis outputs.

## How To Navigate

If you are looking for a specific file, start with the folder that most closely matches the work being done.

- Read background and reference material in [literature_review](literature_review/).
- Open analysis datasets and scripts in [quantitative_analysis](quantitative_analysis/).
- Review interview-based material in [qualitative_analysis](qualitative_analysis/).
- Find drafts, proposals, and final write-ups in [drafts_and_reports](drafts_and_reports/).
- Check supporting documents and media in [additional_materials](additional_materials/).

## Contributing

Future collaborators should keep new files in the same folder structure and use the file name to decide where a document belongs.

- Put survey files, scripts, spreadsheets, and survey reports in [quantitative_analysis](quantitative_analysis/).
- Put interview transcripts, consent forms, and qualitative outputs in [qualitative_analysis](qualitative_analysis/).
- Put literature, books, reviews, and article-style sources in [literature_review](literature_review/).
- Put proposal drafts and final report documents in [drafts_and_reports](drafts_and_reports/).
- Put information sheets, photos, and media files in [additional_materials](additional_materials/).

Keep filenames descriptive and consistent. If a new file does not clearly fit one category, place it in the closest match and update this README if the project structure changes.
