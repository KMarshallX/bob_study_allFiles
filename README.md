## Git Fork, git clone and differences
### Fork copies other people's projects to your account in the cloud (GitHub), allowing you to obtain modification permissions; while Clone downloads cloud projects to your local computer, allowing you to actually start writing code. In collaboration, you usually Fork to get the "copy" first, then Clone to work locally, and finally push the work to the original author through Push and Pull Request.
