what does git clone do; what does GitHub fork do. Differences between git clone and GitHub fork.

Answer: 

(1) Git clone means downloading a repository from GitHub to your own computer. It lets you work on the files locally and make changes using Git.

(2) GitHub fork means making a separate copy of another person’s repository under your own GitHub account. It is often used when you want to modify a project without affecting the original version.

(3) The key difference is that clone works on your computer, while fork works on GitHub online. A common workflow is to fork a project first, then clone your fork, edit it, and later submit changes back to the original project through a pull request.
